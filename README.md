A fast drop-in replacement for csv-reader 1.0.0: a single-pass, hand-written CSV parser that returns byte-identical answers — same columns, rows and error records on every broken row — at roughly 4x the speed of the reference.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
